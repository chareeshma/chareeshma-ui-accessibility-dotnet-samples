# Accessibility Checklist

Use this checklist when building or reviewing samples in this repository:

- Verify WCAG 2.1 AA requirements, including color contrast and text resizing.
- Ensure all functionality is available using a keyboard.
- Provide visible focus indicators and a logical focus order.
- Use semantic HTML and accessible names for interactive controls.
- Associate form fields with labels and provide clear error messages.
- Test with screen readers and automated accessibility tools.
