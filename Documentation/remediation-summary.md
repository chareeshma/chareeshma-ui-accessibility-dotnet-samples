# Accessibility remediation and evidence status

This document records the evidence currently available. It makes no WCAG
conformance claim.

## Automated axe checks

`axe-results.md`, generated by `tests/axe-report.spec.ts`, records seven scans
across the React and Angular applications. The committed report lists zero
violations in each scan and nonzero incomplete-rule counts in several states.
The report records counts, not the identities or manual dispositions of those
incomplete checks. Re-run `npm run test:axe-report` to regenerate it; review the
resulting incomplete checks rather than treating zero violations as conformance.

## Playwright interaction checks

`tests/accessibility.spec.ts` covers dialog/menu keyboard behavior, form
validation and recovery, skip navigation, responsive widths, and axe checks.
Run `npm test` to verify the current source. A committed report is not evidence
that every future or current CI run passes.

## WAVE and manual assistive technology

The maintainer reports that both applications were manually tested using the
WAVE browser extension in Chrome and NVDA. The repository contains WAVE
screenshots and NVDA notes. The available record does not include exact test
dates, full browser/OS and extension versions, or a complete mapping of
screenshots to app states. The older NVDA notes include the previously recorded
environment and findings; see `NVDA-notes.md`.

JAWS testing is not documented as performed. Manual testing status is distinct
from the outstanding documentation work and from the incomplete axe-rule review.

## Implemented changes represented in source

- Native landmarks, headings, labels, table semantics, and dialog elements.
- Associated form labels, hints, errors, focusable error summaries, and status
  messages.
- Dialog focus entry, Tab/Shift+Tab wrapping, Escape dismissal, and restoration.
- Keyboard interaction for the React action menu and documented table keys.
- Visible focus styling and responsive layouts.
