# WAVE scan screenshots

**Status: pending manual WAVE scans.** No WAVE browser extension or WAVE API scan
has been performed for these samples, so this folder intentionally contains no
screenshots or claimed WAVE results. Do not treat the axe report as WAVE output.

To complete this evidence:

1. Start the React and Angular apps using the commands in the repository README.
2. Open each local app in a supported browser with the WAVE browser extension
   installed. Run WAVE on the initial page and, where useful, the invalid-form
   and open-dialog states.
3. Save unaltered screenshots here as `react-initial.png`,
   `react-invalid-form.png`, `react-modal-open.png`, `angular-initial.png`,
   `angular-invalid-form.png`, and `angular-review-dialog-open.png`.
4. Record the browser, WAVE extension version, scan date, and any manual
   interpretation in `../screen-reader-notes.md` or this folder's companion
   notes. WAVE findings require human review; a flagged item is not automatically
   a WCAG failure, and an empty report is not proof of conformance.
