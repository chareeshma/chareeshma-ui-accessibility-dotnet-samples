# Accessibility remediation summary

## Current automated evidence

`axe-results.md` is generated by `tests/axe-report.spec.ts` and records scans of
the React and Angular initial pages, invalid-form states, dialogs, and the React
action menu. The report lists each scan's violations, passing rules, and
incomplete rules. A scan with zero axe violations is a useful check, not a
conformance claim.

## Implemented remediations

- Used native landmarks, headings, labels, table semantics, and native dialog
  behavior rather than replacing semantic HTML with generic elements.
- Associated form labels, hints, field errors, and error summaries; invalid
  submissions move focus to a summary with links back to invalid fields.
- Added dialog focus entry, explicit Tab/Shift+Tab wrapping, Escape dismissal,
  and focus restoration.
- Added keyboard interaction and state announcements for the React action menu,
  and documented the table's roving-tabindex keyboard model.
- Added visible focus indicators, responsive layout, and automated checks at
  mobile and desktop viewport widths.

## Remaining verification

- Capture WAVE extension screenshots for the local app states listed in
  `WAVE-screenshots/README.md`.
- Perform and record manual JAWS and NVDA testing in `screen-reader-notes.md`.
- Review any WAVE findings and axe incomplete results manually, then update this
  summary with verified outcomes. Automated results do not replace testing with
  real assistive technology or user evaluation.
